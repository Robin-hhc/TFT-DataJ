# 定阵后海克斯全量预读

用户于2026-10-09确认实施[调研方案](../research/hex-full-prewarm-20261009.md)。

## 行为

- 选择阵容立即开始预读，不等待攻略详情。全局和阵容主表各读取一次，再补查全局有效候选中主表缺失的精确ID+阶段。
- 未知回合从2-1开始；已知回合优先当前或下一次尚未经过的海克斯阶段，再读其余未来阶段。已经过的阶段不再穷举补查。
- 后台最多一个活跃HTTP，请求之间至少一秒；与普通和实时查询合计最多三个活跃HTTP。选择画面查询暂停新后台请求，已发请求可以完成；即使攻略阻塞也不占后台队列。
- 当前候选优先显示本局已有数据；缺项继续使用现有三项并行和逐项显示。后台与实时请求复用已发出的相同精确补查。
- 全局、阵容主表和补查的有效结果在当前定阵/本局期间保留，不受通用十五分钟磁盘缓存过期影响。补查仅保留目标阵容及来源元数据，避免保留整个检索器响应占用内存。
- 已成功查询却没有目标阵容记录或样本为零，记录本局已查以免重复空查。请求失败不当作无数据缓存，保留来源失败冷却；不循环密集重试。
- 新一局、换阵容、取消固定、换统计版本或退出时取消旧任务并清除本局缓存。普通候选刷新、阶段变化和显示收起不取消本局缓存。
- 严格保留赛季、版本、阵容、海克斯ID、获得阶段及真实样本；缺数据不借其他阶段或全局数值补齐。
