# 中文前缀与图标品质识别

2026-10-21，用户已确认实施。依据[全量可行性核对](../research/suffix-identity-feasibility-20261021.md)，仅在本次独立核准的 19 个纯罗马家族内增加证据通道。设计与验收见[本轮记录](../development-records/2026-10-21-suffix-recognition.md)。

## 目标与范围

完整中文前缀及每卡图标的真实品质共同确定目录 ID，减少细罗马后缀导致的反复 OCR。新通道不改现有无品质上下文的标题接口、装备/条件读取、目录投影、HTTP、排名、会话、浮层、鼠标及捕获调度。

纯 +/++ 及秘法帮派混合家族没有经核准的当前生成阶段表，继续使用原完整标题/描述路径；不得从 `roundStats` 缺失反推身份。当前回合读取复用已有实现，不新增阶段 OCR。此限制来自证据不足，而非否定阶段作为额外证据的可行性。

## 模块及调用

- `hex_quality.read_hex_quality(crop)`：只读中央图标裁图，返回 confirmed/unknown、真实 level 或空值及简短诊断；先缩至固定上限，按前景的空间/颜色证据判断，避开统一绿底和金边。无 OCR、网络、目录、邻卡、文件、线程或截图依赖。
- `hex_family.resolve_family_name(readings,catalog,quality,observed_readings=...)`：独立调用入口，输入可信且不同像素的投票、实际目录及品质。固定已核准家族的来源身份，检查当前全部成员；observed_readings 包括所有可信读数，仅供完整标题否决，不增加票。
- `FamilyNameResolver`：目录的私有快照。只有可信读数命中审核家族字面前缀时才建立；同一帧三张卡共用索引，各卡的品质、投票和冲突证据独立。下一帧重新取快照；不缓存识别 ID。调用方修改目录或返回候选行不能污染已建快照。
- `Vision.analyze_fast`：原有布局和选择场景门槛通过后，传入同一原图的每卡品质回调；仅当可信标题读数命中审核家族前缀时，才裁中央图标 ROI 并读取品质。每卡最多一次，包括 unknown；普通及 plus 卡不增加图标处理。`read_name(crop,catalog)` 默认原有行为保留。
- `Vision.read_name`：记录原有 OCR 输入 shape+SHA，前缀票只计不同像素；原有完整标题读数全部保留。读完初始三个视图，再尝试新通道；后续已有重试若获得足够证据可提前完成，不新增 OCR 视图。

## 身份与拒识合同

1. 至少两次可信完整字面前缀；使用既有 NFKC/空白规范化，保留前缀标点，不做中文模糊纠错。只允许前缀后有限的疑似罗马/标点噪声，噪声不提供 ID。
2. 品质必须来自同卡图标，不能从后缀、ID 数字、效果数值、邻卡或统计反推；unknown 完全沿用旧路径。
3. 已核准家族当前目录必须与审核的 set18、ID、完整名字、品质、图标一致；缺行、额外成员、加号、未知元数据、别名扩展和同品质多 ID 均不启用补全。目录更新不会自动扩大白名单。
4. 任何可信完整合法标题指向另一身份/品质、或出现多个合法完整标题，均否决新通道；不能用更多前缀票或颜色覆盖。所有可信完整标题都参与否决，包括重复像素后出现的不同读数。
5. 无图标、透明/动画、变暗不确定、遮挡不足和混合异常品质均应拒绝自动颜色确认。新颜色和旧标题均无足够证据时保留未确认；不产生建议 ID 的自动统计请求。
6. 新通道只对已经取得的证据负责。提前完成前至少读完初始三个视图，不声称能发现未执行的后续 OCR 读数；已取得的任何冲突不得丢弃。

## 时延与资源预算

- 不增加截图、OCR 或 HTTP 调用，不新增模型、后台线程、定时器或依赖；图标只在固定上限像素处理。
- 同一 engine、同一图像、相同运行环境，修改前后交替测量；至少普通识别、拥抱 I、暗色 II、嘀 I、秘法 II++、动画、非选择、目录缺失/重复、合法标题冲突。
- 每场景先预热，再记录不少于 15 次每版本结果、P50/P95、CPU 与 OCR 调用数。新路径 OCR 次数不得增加；正常/回退场景中位开销目标不超过 5ms，整帧 P95 不得有无法解释的超过 5% 或 10ms 的增加。触及预算需优化、复测，不以总平均掩盖单场景退化。
- 局部像素方法的耗时单列。离线时延不等于真实游戏 FPS；性能测量不与全量测试/构建并行。

## 验收与交付

先观察公开接口行为失败再实现；新增匿名原始图标 fixture 独立来源及哈希，不修改任何既有 fixture/oracle。覆盖 34 条目录成员、金色 I、两票/像素去重、品质未知/错误、完整标题冲突、中文错字/缺字、目录漂移、plus、动画、遮挡、无图标及默认旧接口。

运行受影响测试、公共和私有统一门槛、数据故障注入、已批准原图、相关 Qt/会话回归、独立审阅和串行性能对照。登记确切方法 ID、新 fixture 和实际结果。保留其他未提交改动；运行源码、干净构建、实际 EXE、本机更新分别验收，不用源码测试代替包验证。
