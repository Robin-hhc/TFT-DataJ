# 海克斯动画恢复与标题共识

## 用户问题与证据

用户要求全面检查多项海克斯未识别。本次冻结了 2026-10-10 20:19 前的 34 个本机问题案例：30 个海克斯案例、1 个大厅人工记录、3 个详情取条件记录。原图及录制输出保留，不以旧浮层文字作为新选项答案。

大量海克斯案例捕获于刷新动画：卡片透明或半透明、标题消失或下移出固定识别区域；此时没有足够可靠的标题像素。现有流程在检验标题签名前即归档为识别问题，并使动画恢复继承 1.5 秒 OCR 冷却。另一个清晰案例“秘法帮派 II++”在二值与宽图各得到一次正确的完整标题，但因正确读数不在同一个重试分组内而未确认。

## 采用方案

1. 保持选择期间原有 0.5 秒截图策略，不增加截图或全屏检测。
2. 海克斯三槽观察有合法区域但标题签名不可验证时，清理旧统计，只暂存签名所需的区域元数据。即使该帧暂未读出回合，也应用这一规则；回合仍须确认后才能显示排名。动画帧不作为自动识别失败归档。
3. 利用已有截图在后台检查这些小区域的标题笔画像素。持续透明、暗淡或缺失的标题不触发重复 OCR；不能通过降低置信度或猜测旧标题来恢复结果。
4. 下一个标题签名可验证的帧立即请求一次 OCR，不继续等待动画帧留下的 1.5 秒冷却和 2 秒重复读取门槛。首次进入该阶段也必须通过后续独立帧确认，OCR 输入帧不能确认自己；目录缺名结果也遵循确认规则再归档。
5. 未知棋盘等没有三槽区域的场景保留原有后退策略；装备优先路由不被动画门控阻断。退出选择或进入装备选择清理动画门控及其独立帧确认标记。停止、版本变化、会话变化、定阵变化与普通失效均清理门控；迟到回调不能恢复旧排名。
6. 标题确认允许不同直接 OCR 视图之间形成共识：至少两次完整、同一目录身份的精确标题匹配，置信度不低于 0.90。若重试后仍只有一次完整合法匹配，最多加一次原色紧裁图补读；缺目录、目录歧义或冲突不增加补读。罗马数字及 `+` 后缀不重写，不用建议身份自动查询统计。
7. 像“白银命运”这种标题像素稳定但 DataJ 缺项的情况继续归档，拒绝借用 `+ / ++` 的 ID 或排名。

## 验收

- 动画期间多次既有截图不造成 OCR/HTTP 循环，也不保存重复识别失败案例。
- 动画结束后，在下一次可验证截图中排队 OCR；再次独立帧确认后才发布排名。
- 退出选择、窗口/版本/会话变化及装备选择不会导致旧结果复活。
- 清晰“秘法帮派 II++”匿名标题原图可确认为来源 ID 30679；单次、低置信度、不同后缀与冲突读数仍拒绝。
- 全部已审阅本机截图可回放；明确记录“安全拒绝动画图”和“已确认身份”，不能把两者混为全部成功识别。
- 相关公开测试、完整数据展示回归和原图验证通过后重启本机助手。
