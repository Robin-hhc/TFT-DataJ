# v0.2.20 · 海克斯识别与有界故障恢复

2026-10-21 · Windows 10/11 x64 便携测试版候选，远端与新包验收完成前尚未公开。

本版合入此前仅在本机交付的识别修复，并修正坏缓存恢复与持续来源异常时的自动重试。

- 海克斯标题：处理已核对的暗色「拥抱 II」、细小罗马数字/加号和「弒/弑君突刺」字形场景。对已审核家族使用中文前缀与图标品质辅助确定身份，保留完整标题冲突和歧义保护，不统一替换后缀字符。
- 缓存：响应先通过业务校验再保存；遇到旧坏缓存精确失效后重新获取，避免网站恢复后仍不断读到坏值。新坏响应不会覆盖最后一份好目录；本地目录兜底明确标记，统计不借用过期数值。
- 持续故障：同一后台预热任务累计失败三轮（含首次）后停止，最多两次自动重试，每次至少60秒且遵守共享冷却。部分成功不清零失败计数，旧Timer及重复start不能绕过；成功内容保留，手动查询仍可用。
- 同画面查询：已确认选项获取全局统计失败后，不再无限重复OCR或联网；可用侧键或「立即补查一次」手动重试。换牌检测及原有两次未确认标题补读继续保留。
- 头像与性能：英雄头像保留原图。正常固定场景的识别、目录、头像及帧处理对照达到原预算；仅清理已有坏缓存的恢复请求比同候选正常冷取多约7至14毫秒本地处理成本，已由用户接受。该差值不包含真实网络或失败冷却等待。

v0.2.19 公开前CI发现两处测试规范化/同步缺陷，已红色复现并最小修正：临时目录按规范路径比较，异步刷新在对应结果完成后检查来源元数据。保留250ms发布检查和原业务断言，错误来源与真实沙箱越界仍被拒绝；未修改运行代码、依赖或资源。原候选及失败报告保留，新包使用新版本与新源码指纹。

本机已有46张批准原图及实际EXE验收基线；本版完整源码门槛、故障注入、精确提交CI与新EXE验收结果随后按实际报告追加，不借用旧包结果代替。

仍有15份历史截图待独立核对，未算作通过；完整后缀/动画/缩放矩阵、双行已拥有列表和部分详情布局保留能力边界。来源无数据或同名同品质多身份时继续提示未确认，不猜ID或借别的阶段统计。实战FPS、MuMu合成、物理侧键及另一台电脑本轮未重新验收。

最终源码SHA、ZIP大小及校验和、CI与公开下载核验在实际完成后追加。下载ZIP后完整解压，运行 `TFT-DataJ.exe` 并保留 `_internal`，无需Python。退出旧助手后运行新版本，原设置和旧版本目录保留。原始截图、用户日志及含本机路径的完整报告不作为Release附件，公开脱敏摘要。
