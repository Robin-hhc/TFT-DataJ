# v1.0.0 · 首个正式版

2026-10-21 · Windows 10/11 x64 便携正式版。

左下角统计版本选择框下方增加小号灰色 `v1.0.0`，方便确认正在使用的助手版本。悬停说明区分程序版本与 DataJ 统计版本。版本号只作辅助信息，保持原有侧栏布局和操作入口。

本版保留 [v0.2.20](v0.2.20.md) 已交付的海克斯标题与已审核家族品质辅助识别、坏缓存恢复、持续来源故障的自动重试上限及英雄头像原图行为。正式版沿用现有功能与证据边界。

同时纳入此前已验收的点击外部自动收起功能：默认开启，左键在助手外单击会收起面板，原点击继续交给目标窗口。拖动、助手菜单和对话框不触发；可在“识别 / 设置”关闭。此功能的源码交互回归与实际包检查分别记录，物理输入的现场游戏体验仍须实测。

发布验证正在执行，最终源码、精确提交 CI、公共回归、批准私人原图、独立解压后的实际 EXE 离线/联网验证及下载校验结果将在完成后补入本页。以本版实际报告为准，旧版测试数量不作为本版通过证明。

历史待核对截图不计为通过；完整后缀、动画与缩放矩阵、双行已拥有列表及部分详情布局仍有覆盖边界。来源无数据或身份有歧义时继续提示未确认。实战 FPS、MuMu 合成、物理侧键和另一台实体电脑须分别实测，源码或本机包检查不能代替这些结论。

下载 `TFT-DataJ-1.0.0-windows-x64.zip`，退出旧助手后完整解压，运行 `TFT-DataJ.exe` 并保留 `_internal`。无需安装 Python 或 OCR 环境，用户设置与缓存继续保存在 `%LOCALAPPDATA%\TFT-DataJ`。本版无自动更新，旧目录可保留。原始截图、用户日志与含本机路径的完整报告保留本机。
