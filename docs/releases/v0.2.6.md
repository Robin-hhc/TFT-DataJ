# v0.2.6 · 海克斯身份、详情取条件与本机问题记录

2026-10-07 · Windows 10/11 x64 便携测试版。修复等价海克斯别名和普通装备大图标详情读取，新增本机问题截图归档及核对后原图复验。

## 下载与升级

在 [v0.2.6 发布页](https://github.com/Robin-hhc/TFT-DataJ/releases/tag/v0.2.6) 下载 `TFT-DataJ-0.2.6-windows-x64.zip` 及同名 `.zip.sha256`。

更新时先退出旧助手，完整解压新版到新文件夹，双击 `TFT-DataJ.exe`；保留旁边的 `_internal` 文件夹。无需安装 Python 或 OCR 环境。设置、缓存和问题记录保留在 `%LOCALAPPDATA%\TFT-DataJ`，无需从旧程序目录复制；旧包也可保留用于回退。新版不包含开发机的私人游戏图片或缓存。

## 本版改动

- **等价海克斯使用同一目录身份。** 名称、赛季、品质、图标和描述完整等价，且当前统计版本只支持其中一个有效 ID 时，等价别名映射到该身份。OCR、手动条件查询及本局快捷条目使用同一投影；原始目录不改写。真正不同品质或属性的选项继续分别确认，元数据缺失、多个有效 ID 或统计不可用时保持待确认，不按均排、阵容样本或当前阶段猜身份。
- **修复普通4K装备大图标详情。** 增加与大图标匹配的主标题候选，保持原普通、库存和英雄布局，以及一次主标题读取。真实巨人腰带原图可解析为 `equip/1007`，不会把下方穿戴者婕拉当成装备名称；失败时细分原因并保留旧检索条件。
- **明确从游戏取条件的入口。** 在游戏打开名称详情、保持可见，直接按鼠标后退侧键即可读取并检索，无需先点击助手按钮。“从游戏取条件”按钮会立即读取当前详情；“记为已选”仅保存本局检索快捷条目，不替玩家在游戏内选择或购买。
- **失败截图只在本机保存。** 识别、详情读取或数据查询失败时复用已经捕获的绑定游戏图，后台写入，不增加自动截图或 OCR。新增“记录问题”手动反馈和“记录文件夹”入口。最多100例、500 MiB，重复问题保留首帧，满额停止新增，不删除或覆盖旧样本，不自动上传；自动保存单任务，15秒冷却。
- **先核对，再复验原图。** 新记录保持 `pending_review`；只有逐图核对并提供绑定图片哈希、赛季和版本的合法 `expected.json`，才执行真实识别回放。场景、身份、详情种类及海克斯阶段分别检查，错误种类即使 ID 相同也失败；pending 不算通过。此工具不验证排名、联网恢复或游戏性能。

EXE 问题图保存在 `%LOCALAPPDATA%\TFT-DataJ\bug-cases\`；源码运行保存在 `work/companion/bug-cases/`。装备底部捕获路径的 `item_band` 会按原坐标补黑未捕获的上半部分，不能当作完整全屏图验证。

## 已完成的源码验证

本机完整检查 **519 项通过，0 失败、0 错误、0 跳过**，耗时95.701秒；**356组冻结接口响应到实际Qt界面的数据显示回放**、**原有详情21/21原图回放**及**8种错误注入**通过。既有详情集含开发图片、重复事件和拒绝负例，不是21张新增独立装备正例。

本次巨人腰带使用真实3840×2160游戏原图，旧代码拒绝、新代码解析并经控制器序列化为18.3版本装备条件。控制器验收中的捕获/前台适配及网络响应为模拟，未实测真实鼠标侧键、完整现场端到端耗时或FPS。真实失败归档没有 oracle 时 `passed=0`，核对后实际OCR `passed=1`；把种类错改为 `hero`、保持 ID `1007` 时 `failed=1`，原图及原记录哈希不变。

用户口称“大剑”的目录名称是暴风之剑（1001），尚无它的独立原图验收。此前一次真实单条件在线查询失败后即停止，没有重试或请求巨人腰带统计；该次失败不是零样本，也不据此断言服务持续不可用。冻结数据显示、原图身份和在线统计可用性各自独立，不能相互替代。

## 本版交付门槛与命令

必须从本版源码重新构建实际ZIP，在仓库外含中文和空格的目录解压，隔离Python、PATH、用户目录及模块来源后运行真正的EXE。保留文件哈希、356组数据显示、模型、WebEngine、TLS和真实2-1截图识别门槛。本版新增等价海克斯别名及不同variants保留、问题图无损PNG保存/去重/无oracle保持pending，以及真实4K巨人腰带 `equip/1007` 主标题不误读穿戴者的诊断。验证器将本机哈希锁定的私图复制到外部临时目录，不把图片装入ZIP。实际包结果记录在本版 `.validation.json`，不复用旧版包结果。

构建与验证命令（在仓库根目录执行）：

```powershell
work\p0-runtime\Scripts\python.exe packaging\build_windows.py --version 0.2.6
work\p0-runtime\Scripts\python.exe packaging\verify_windows.py dist\TFT-DataJ-0.2.6-windows-x64.zip --online
```

源码及已核对私有样本的统一检查：

```powershell
work\p0-runtime\Scripts\python.exe -X utf8 tools\validate_data.py --include-private --release-gate --bug-cases-dir work\condition-sword-20261007\verified-cases --report work\data-validation\v0.2.6-source.json
```

提交对应CI通过、实际ZIP验收通过，且ZIP与SHA-256附件上传完成后，才公开预发行版。实际EXE结果以本版 `.validation.json` 为准；下载文件的大小与校验值以发布页及 `.zip.sha256` 附件为准。

便携隔离验收仍在构建机上进行，不等于第二台实体电脑或其他硬件验收。未签名、无安装器和自动更新；游戏FPS、多局现场识别及全屏点击穿透的限制保持不变。
