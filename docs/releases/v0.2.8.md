# v0.2.8 · 补齐定阵海克斯小样本排名

2026-10-08 · Windows 10/11 x64 便携测试版。

[下载便携包](https://github.com/Robin-hhc/TFT-DataJ/releases/tag/v0.2.8)，完整解压后运行 `TFT-DataJ.exe`；保留 `_internal`，无需安装 Python 或 OCR 环境。

## 改动

- 固定阵容后，阵容表缺失的海克斯按同版本、同 ID、同阶段精确查询检索器。已核对野怪小蓝 3-2 的四之力 4.23/13、厨神阿福 4.54/13、电火花 II 4.75/8；不足 50 局仍显示并标「少」。
- 修复短暂失焦时丢弃阵容成功回调、一直显示「读取中」的问题；浮层的前台、会话和新鲜截图限制保留。
- 全局先显示，后台补阵容；每组最多三个去重条件，复用版本及阶段缓存。失败保留已有结果与来源冷却，重试不会清掉同组已成功的阵容排名。
- 无效补查响应不会作为有效缓存阻断重试；来源恢复后正常重查，有效的其他条件继续使用缓存，请求节流不变。
- 区分未识别、来源暂无统计、阶段缺项与查询失败；不借用整体均排、其他阶段或相似名称来填空。

## 验证

完整源码回归602项通过，0失败、0错误、0跳过；356组冻结数据显示、已核对3-2原图1/1及8项数据显示故障注入检查均通过。独立Spec与Standards审查完成。

专项回归先确认失败再修复，覆盖阶段与版本隔离、低样本、空结果、零样本、错误阵容、来源冷却、短暂失焦、重试及实际 Qt 显示。冻结矩阵仅更新缺项文案，165 份响应与数值参考未改写。

独立空缓存真实 HTTPS 补查的四次请求用时 4.302 秒，三项阵容阶段值均与冻结参考一致。隐藏 Qt 回放图已查看，数值、小样本标记及颜色可读，无标签截字。
