# v0.2.5 · 紧凑界面、统一搜索与出场率排序

2026-10-07 · Windows 10/11 x64 便携测试版。精简阵容助手的顶部、搜索和列表工具栏，保留定阵、复制码、攻略及本局已选资源。

## 下载与升级

在 [v0.2.5 发布页](https://github.com/Robin-hhc/TFT-DataJ/releases/tag/v0.2.5) 下载 `TFT-DataJ-0.2.5-windows-x64.zip`。先退出旧助手，完整解压到新文件夹，双击 `TFT-DataJ.exe`；保留旁边的 `_internal` 文件夹。无需安装 Python、OCR 或开发环境。

设置与缓存保留在 `%LOCALAPPDATA%\TFT-DataJ`。程序会阻止同时启动多份助手；更新前请关闭旧版。默认鼠标后退侧键补查，`Ctrl+Alt+F10` 也可补查，`Ctrl+Alt+F12` 退出。

## 本版改动

- **顶部合为一行。** 显示当前定阵状态、复制码、新一局和窗口动作；长阵容名省略显示，悬停可看完整名称。退出 × 移到“收起”左侧，最右侧用面板图标加“收起”；收起后点击浮动标记恢复，实际退出会结束程序。
- **搜索只保留一个框。** 输入文字筛选当前阵容，选择下拉中的完整阵容可直接固定；点选英雄、海克斯、装备、转职或羁绊才设置单条件检索。候选显示类别与身份区别，方向键选中后回车确认，直接回车不会猜第一项。
- **列表更紧凑。** 移除收藏和常驻刷新，卡片直接固定或查看已固定阵容；已选资源与条件仅在有内容时占行。请求失败时显示局部“重试”，没有匹配结果单独提示。
- **出场率使用真实统计口径。** 平均排名从低到高，出场率按 DataJ 的 `pickRate` 从高到低，同值保留来源顺序；显示原始两位小数，不乘 100、不加百分号，也不以样本数代替。
- **最小样本可选。** 默认 50 局，可选 1、10、50、100、300、500、1,000、3,000、10,000 局。全局榜单按所选门槛请求，条件检索按当前条件内样本过滤；切换门槛或版本后，旧请求与缓存不会覆盖新列表，无结果不借用其他范围的数据。英雄出装与装备持有者仍使用各自的 50 局门槛。
- **保留定阵与攻略版本提示。** 收起恢复时保留搜索、条件、已选资源、定阵、排序、样本门槛及攻略位置。历史统计下打开原站最新攻略时，仍明确显示两边版本；复制码、强化和出装查询跟随所选统计版本。
- **新增专用应用图标。** EXE、窗口及快捷方式可使用同一套图标，包含适配不同大小的 Windows 图标资源。

查看或检索资源不会记为已选。实际拿到该项后点击“记为已选”，以后可点快捷条目检索；自动记选暂未开放。“从游戏取条件”仍需先打开名称详情，无法确认时可用同一个搜索框。

## 验证范围与交付

本机源码完整验收 **411 项通过，0 错误、0 失败、0 跳过**，包含 **356 组冻结接口响应到实际 Qt 界面的数据显示回放**；8 种错误注入、9 项异步集成操作均通过。追加覆盖了完整收起恢复、切回游戏被拒绝后的可用性、真实子进程退出。

布局检查覆盖本机 125% 缩放和通过 Qt 环境变量强制的 150% 有效缩放；实际 EXE 诊断另记录运行时的有效缩放。冻结数据回放不等于当日网站 DOM 对账；已有真实截图 OCR 不代表新增对局现场识别或游戏 FPS 验收。便携隔离检查仍在同一台实体电脑上进行，尚未完成第二台电脑实测。
