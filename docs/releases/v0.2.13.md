# v0.2.13 · 海克斯预读与奥恩装备浮层修复

2026-10-09 · Windows 10/11 x64 便携测试版。

[下载便携包](https://github.com/Robin-hhc/TFT-DataJ/releases/tag/v0.2.13)，退出旧助手，完整解压后运行 `TFT-DataJ.exe`，保留 `_internal` 文件夹，无需安装Python或OCR环境。

本版同时包含定阵海克斯全量预读和奥恩装备浮层修复。固定阵容后立即预读未来阶段缺项，结果保留整局；装备卡框短暂识别不到时，只要原位置的名称、选择标题和图像尺寸一致，已确认排名及查询继续保留。真正换选项仍会清除旧数据。

v0.2.11不含奥恩修复。v0.2.12候选因GitHub CI中的一项海克斯并发测试失败而未公开：测试没有保证失败项出现时另两项已经成功，第三项可能抢先失败并建立共享冷却。本版用事件固定该测试的场景，保留排名、来源、失败重试及冷却断言；生产冷却规则不变。

发布要求完整源码与356组数据显示、真实图片回放、故障注入、实际便携EXE离线/联网验证和GitHub CI均通过。本轮采用留存图片与控制时序测试，未重新开局验证下一次奥恩选择。
