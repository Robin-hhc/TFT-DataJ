## 改动

- 补齐海克斯标题下沿，修复真实3-2画面中“星界赐福 III”截字和品质后缀缺失；继续要求精确身份与多视图共识。

- 检索重试成功后清除旧来源错误提示，迟到回调不覆盖当前查询状态；新增两项Qt回归。
- 新增真实标题、签名、回合、退出三帧和装备详情裁片回归；完整私人画面仅留本机，公开裁片保留所需原像素并遮黑其他区域。

在仓库根目录执行：

```powershell
work\p0-runtime\Scripts\python.exe -X utf8 tools\validate_data.py --include-private --release-gate --bug-cases-dir work\live-match-20261007\reviewed-cases --report work\data-validation\v0.2.7-source.json
work\p0-runtime\Scripts\python.exe -X utf8 packaging\build_windows.py --version 0.2.7
work\p0-runtime\Scripts\python.exe -X utf8 packaging\verify_windows.py dist\TFT-DataJ-0.2.7-windows-x64.zip --online
```

发布包从最终提交构建；实际ZIP在仓库外、中文及空格路径、无可用Python环境中运行EXE诊断。发布页保持草稿直到本版CI、包验证及ZIP/checksum附件上传通过。附件为 `TFT-DataJ-0.2.7-windows-x64.zip` 与 `.zip.sha256`。
