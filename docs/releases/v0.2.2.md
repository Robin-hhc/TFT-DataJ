# v0.2.2 · 性能与显示稳定性更新

Windows 10/11 x64 便携测试版。改进手动查询时的卡顿、排名闪现和连续截图的内存占用，并补齐数据显示回归。

## 下载与升级

下载本页附件 `TFT-DataJ-0.2.2-windows-x64.zip`，先退出旧助手，再完整解压到新文件夹并运行 `TFT-DataJ.exe`。不需要安装 Python 或 OCR 环境，保留旁边的 `_internal` 文件夹。

设置与缓存继续使用 `%LOCALAPPDATA%\TFT-DataJ`。默认鼠标后退侧键补查，`Ctrl+Alt+F10` 同样可用；`Ctrl+Alt+F12` 退出。不要同时运行两版助手。

## 本版改动

- 修复手动刷新和第一次阶段探测反复清空已有均排的问题，选择画面仍在时持续检查。
- 修复等待较久后再次换牌停止识别、冷却期间丢失重试等边界情况；新画面仍会撤掉旧排名。
- 图像处理移至后台，仅检查相关文字区域，限制 CPU 线程；同一组选项补查复用已确认的识别结果。
- 释放后台任务对旧截图的引用，减少连续截图的内存积累。
- 阵容数据读取失败时，侧键可重试该查询，无需重复 OCR；全局查询失败不会重新显示旧值。
- 英雄单件与三件套装备按至少50局筛选；拒绝错误身份、异常数值及阶段不匹配的数据。
- 增加截图释放、显示稳定性、版本切换、缓存、数据错误与失败恢复检查，并接入 Windows CI。

## 本机验证

124项测试、356组数据显示回放全部通过，6种数据故障注入均被捕获。便携EXE另在仓库外中文目录、隔离Python/PATH的环境中验证界面、真实2-1截图识别、统计显示、WebEngine及本机TLS。

同一台电脑使用真实4K截图回放，每次创建新图片，统计使用固定快照：

| 指标 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 新选项识别中位数 | 512 ms | 233 ms |
| 同组选项补查中位数 | 512 ms | 30 ms |
| 界面事件最长停顿 | 173 ms | 9 ms |
| 主进程峰值内存 | 666 MiB | 368 MiB |

连续200次检查未观察到截图持续积累。以上不含真实MuMu截图、网络等待、首次模型加载、浏览器子进程和游戏帧率，不是跨电脑性能保证。仍保留测试版标记，独立多局和其他实体电脑验收尚待补充。
