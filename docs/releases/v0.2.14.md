此候选没有公开 Release 或 tag。源码 `494218449565f69ed7686bba5cc8a31ce394c386` 的[CI](https://github.com/Robin-hhc/TFT-DataJ/actions/runs/38058970801)有一项投影回归失败：测试停用了采集 timer，却用超过生产 1.5 秒门槛的旧画面等待统计显示。本机源码与 EXE 验证通过不能代替该门槛。

保留候选 ZIP 于本机 `dist/archive/candidates/v0.2.14/`，SHA-256 `9a56282d0d3fbf48c547e6d01007ca2ebb9bd3be364811e0197330793434cf47`；离线实际 EXE 验证为 3023 文件哈希、356 显示通过，联网目录/头像也通过。原报告与 CI 失败保留在 `work/release-0.2.14/`。最终交付转到[v0.2.15](v0.2.15.md)，原候选不覆盖或重用。

本版保持现有 Python/PySide6 单实例桌面主程序架构，WebEngine 另有辅助进程，落实三项改进：

- 海克斯统计保存明确的版本、阶段、阵容、实体、数值、样本及来源。刷新保留和颜色读取结构化事实，显示文案变化不再影响统计状态。
- 阵容列表、定阵详情、目录和英雄出装的排队查询在执行前检查有效性。已经过期的任务不再发送来源请求，最新任务继续完成；执行中的 HTTP 仍通过回调范围检查隔离。
- 切换统计版本继续使用应用内同一来源预算，保留总并发 3、后台并发 1、请求节奏及失败冷却。统计缓存和在途结果仍按完整请求身份隔离；目录本身只按赛季查询。

便携诊断也适配了相同的调度参数和取消语义，保留既有攻略、复制码、版本及条件查询断言。来源响应缺项、几何上下文和损坏缓存的独立修复不能从本版架构优化推断已完成。

本地源码验收、远端 CI 和实际 ZIP 验收是独立门槛。此候选未上传公开附件。原始报告、批准原图和其他私人样本只保留本机，不进入 Git 或 ZIP；pending 记录不计为通过。

构建和在线包验证命令：

```powershell
work/p0-runtime/Scripts/python.exe -X utf8 packaging/build_windows.py --version 0.2.14
work/p0-runtime/Scripts/python.exe -X utf8 packaging/verify_windows.py dist/TFT-DataJ-0.2.14-windows-x64.zip --online
```
