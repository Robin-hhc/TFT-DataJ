# v0.2.4 · 最新版本、装备浮层与数据校验

Windows 10/11 x64 便携测试版，包含启动默认最新统计版本、装备英雄显示与浮层稳定性修复，以及更完整的排名回归检查。

## 下载与升级

下载附件 `TFT-DataJ-0.2.4-windows-x64.zip`。先退出旧助手，完整解压到新文件夹，双击 `TFT-DataJ.exe`；保留旁边的 `_internal` 文件夹。无需安装 Python、OCR 或开发环境。

设置与缓存保留在 `%LOCALAPPDATA%\TFT-DataJ`。程序会阻止同时启动多份助手；更新前请关闭旧版。默认鼠标后退侧键补查，`Ctrl+Alt+F10` 也可补查，`Ctrl+Alt+F12` 退出。

## 本版改动

- 启动时读取 DataJ 版本列表，默认使用网页最新版本；运行中不会反复检查版本，仍可手动切换历史版本。切换时立即撤下旧版阵容排名，加载失败或旧请求迟到不会恢复旧卡片。
- 减少海克斯与装备排名反复撤下、重绘和清空头像；同一组已确认选项复用识别结果，失败请求可通过侧键补查。
- 普通成装、奥恩和光明装备优先加载对应范围的英雄；修复基础英雄 ID 与星级图鉴 ID 不一致时头像缺失的问题。
- 装备排名框缩小并下移，保留两位英雄、均排颜色及样本；4K、200% DPI 验证画面中从 500×264 缩到 400×192 像素，下移 84 像素。按实际字体行高自适应，避免不同 Windows 默认字体造成文字裁切。
- 检索器增加本局已选快捷条目、明确确认及“从游戏取条件”入口，文字搜索折叠为保底；所有输入继续只使用一个检索条件。
- 拒绝缺失或异常英雄名称，避免装备显示中断或阵容详情假显示已固定。
- 加强数据检查：零样本显示、排序反转、版本及范围隔离，冻结数据的请求或案例被误删时检查会失败。

## 本局资源的确认方式

查看或检索一个海克斯、装备、英雄本身不会记为已选。确认你实际拿到该项后，点击“记为本局已选”，以后可直接点快捷条目检索。

从游戏取条件需要先打开游戏中的名称详情，再触发一次侧键或入口；无法确认时保留原条件，可用文字搜索。自动记选暂未开放，避免把没有选择的候选加入本局记录。

## 验证范围

本机完整源码检查 **384 项通过，无跳过**，包含 **356 组真实冻结响应到最终 Qt 界面的回放**；阵容与检索器116组、英雄出装144组、海克斯72组、装备24组。八种错误注入全部捕获。本轮另外采集 18.3 的18个接口响应，30组最新数据界面抽查通过。

发布包由当前提交重新构建。便携验证在仓库外中文目录解压实际 ZIP，通过限制 Python、PATH、用户目录和模块来源运行实际 EXE；包含模型、WebEngine、TLS、资源输入及四领域显示回放。ZIP 的 `.sha256` 可用于核对下载文件。

这些数据检查是接口与展示规则的抽样对账，不验证网站上游统计计算或全部实体。真实历史截图回放与新对局现场验收分开记录；独立多局游戏帧率、全部详情布局和第二台实体电脑仍未完成验收。
