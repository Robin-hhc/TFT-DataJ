# v0.2.15 · 结构化统计与查询生命周期优化

2026-10-10 · Windows 10/11 x64 便携测试版。

[下载便携包](https://github.com/Robin-hhc/TFT-DataJ/releases/tag/v0.2.15)。退出旧助手，完整解压 `TFT-DataJ-0.2.15-windows-x64.zip`，运行 `TFT-DataJ.exe` 并保留 `_internal`；无需安装 Python 或 OCR 环境。

本版保持现有 Python/PySide6 单实例桌面主程序架构，WebEngine 另有辅助进程，落实三项改进：

- 海克斯统计保存明确的版本、阶段、阵容、实体、数值、样本及来源。刷新保留和颜色读取结构化事实，显示文案变化不再影响统计状态。
- 阵容列表、定阵详情、目录和英雄出装的排队查询在执行前检查有效性。已经过期的任务不再发送来源请求，最新任务继续完成；执行中的 HTTP 仍通过回调范围检查隔离。
- 切换统计版本继续使用应用内同一来源预算，保留总并发 3、后台并发 1、请求节奏及失败冷却。统计缓存和在途结果仍按完整请求身份隔离；目录本身只按赛季查询。

便携诊断适配相同的调度参数和取消语义，保留既有攻略、复制码、版本及条件查询断言。投影回归明确新鲜画面前置条件，并保护“过期不绘制、新鲜后正确投影”；生产 1.5 秒画面保护保持有效。来源响应缺项、几何上下文和损坏缓存的独立修复不能从本版架构优化推断已完成。

[v0.2.14 候选](v0.2.14.md)因 CI 投影测试的画面时间前置条件失败未公开；保留其源码、失败报告、原 ZIP 和哈希，本版从通过门槛的新提交重新完整构建。

本地源码验收、远端 CI 和实际 ZIP 验收是独立门槛。发布附件提供 ZIP、SHA-256 和去除本机路径的实际 EXE 隔离验收摘要；最终发布说明记录对应提交与 CI。原始报告、批准原图和其他私人样本只保留本机，不进入 Git 或 ZIP；pending 记录不计为通过。

构建和在线包验证命令：

```powershell
work/p0-runtime/Scripts/python.exe -X utf8 packaging/build_windows.py --version 0.2.15
work/p0-runtime/Scripts/python.exe -X utf8 packaging/verify_windows.py dist/TFT-DataJ-0.2.15-windows-x64.zip --online
```

隔离验证在构建电脑上运行真正的 EXE，检查包内文件哈希、数据显示、OCR 模型、WebEngine、Windows TLS，以及有本机输入时的真实留存截图；联网项是 DataJ 目录 HTTPS 与真实英雄头像，不验证实时统计排名。它不证明第二台实体电脑兼容、物理侧键、MuMu 合成器或真实对局 FPS。
