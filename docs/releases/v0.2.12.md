# v0.2.12 · 奥恩装备浮层查询修复

2026-10-09 · Windows 10/11 x64 便携测试版。

[下载便携包](https://github.com/Robin-hhc/TFT-DataJ/releases/tag/v0.2.12)，退出旧助手，完整解压后运行 `TFT-DataJ.exe`，保留 `_internal` 文件夹，无需安装Python或OCR环境。

此前，装备卡框暂时识别不到会清空已确认的装备组，导致已有均排消失、正在获取的阵容排名被丢弃。现在会继续核对原位置的装备名称和选择标题，文字及图像尺寸一致就保留浮层和查询；名称、标题、尺寸或选择槽数变化时仍立即清除旧数据。海克斯粗提议也遵守已确认装备文字的校验。

本版包含v0.2.11的定阵海克斯全量预读、未来阶段优先和整局缓存。v0.2.11已经发布的文件保持原样；该版本未纳入奥恩修复。

新增8项公共生命周期回归和1项私有真实奥恩图片派生回放，公共CI不依赖游戏截图。发布门槛包括完整源码与356组数据显示检查、实际便携EXE离线/联网验证和GitHub CI；本轮不重新开局，不宣称完成修复后的下一次奥恩选择实战确认。
