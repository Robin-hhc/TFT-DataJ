# TFT-DataJ v0.2.16 本机交付

本版本修复两处已由原图复现的识别问题：

- 「弑君突刺」的 OCR 字形「弒」与目录不匹配。仅对独立核对的 S18 完整标题及实体启用字形等价，保留两次可信读数、冲突与同名歧义保护。
- 暗色「拥抱 II」标题达不到固定白色门槛。增加相对对比度重试，保留完整纵向标题区域和罗马数字后缀的精确共识。

新增 24 项公共回归和两张匿名真实标题裁图；批准完整原图由 34 例追加为 36 例，旧批准哈希不变。实际 ZIP 另用两张完整原图核对场景、回合、三个 ID、确认状态与槽位顺序。

本轮仅按用户要求重新打包并更新本机，未公开发布 GitHub Release。源码、包验收与本机部署的实际结果见[开发记录](../development-records/2026-10-18-recognition-fix.md)。现场游戏 FPS、物理侧键和另一台电脑不属于本轮静态回放结论。
