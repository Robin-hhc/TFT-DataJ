# v0.2.1 · Windows 便携测试版

首个可直接下载运行的便携版本：无需安装 Python 或 OCR 环境。同时修复检索器的小样本排序问题，避免只有一两局数据的阵容排到推荐列表前面。

发布日期：2026-09-28。当前为 **Pre-release / 测试版**，目标系统为 Windows 10/11 x64，主要适配 MuMu 中的金铲铲。数据目录限定 S18，统计版本可在助手中选择。

## 下载与首次使用

| 附件 | 用途 |
| --- | --- |
| [TFT-DataJ-0.2.1-windows-x64.zip](https://github.com/Robin-hhc/TFT-DataJ/releases/download/v0.2.1/TFT-DataJ-0.2.1-windows-x64.zip) | 程序包，约268 MB；普通使用下载这个文件 |
| [TFT-DataJ-0.2.1-windows-x64.zip.sha256](https://github.com/Robin-hhc/TFT-DataJ/releases/download/v0.2.1/TFT-DataJ-0.2.1-windows-x64.zip.sha256) | 可选的文件完整性校验值 |

1. 将 ZIP **完整解压**，双击 `TFT-DataJ.exe`。请保留旁边的 `_internal` 文件夹，不要在压缩包内直接运行。
2. 打开 MuMu 和金铲铲，等待助手准备完成。唯一的 MuMu 游戏窗口会自动连接；多开时需在设置里选择窗口。
3. 确认左侧统计版本。在“选阵容”页选择一个检索条件，点击阵容卡片即可固定本局阵容；未定阵也可以查看全局统计。
4. 点击“收起”，回到游戏。自动检查海克斯阶段和装备选择，鼠标后退侧键可随时补查。

OCR 模型和运行库随包提供；DataJ 统计、攻略及头像仍需联网。GitHub 自动提供的 **Source code** 是源码压缩包，不是上述程序包。

## 本版新增与修复

- **便携运行**：打包 Python、OCR 模型、界面运行库和内置网页组件，无需另装开发环境；设置、缓存与日志保存到 Windows 用户目录。
- **修复检索器排名**：先排除当前检索条件下不足50局的阵容，再排序、搜索、收藏筛选及分页。界面标明“样本≥50局”，旧缓存也会应用这条规则；没有达标阵容时显示空结果。
- **改善启动排查**：启动失败记录日志，并随包提供“检查运行环境.cmd”。

例如，“黑暗仪式”此前会把仅1局样本、均排2.00的“裁决螳螂”排在前面。修复时同版本查询仅“黑暗仪式蜘蛛”和“重装女警”达到50局门槛，实际界面与打包后的 EXE 均已验证此结果。统计会随来源更新；助手仍提供“均排优先 / 样本优先”，不保证与网站默认出场率排序完全相同。

## 包含的主要功能

- **海克斯浮层**：自动检查2-1、3-2、4-2阶段并识别候选，显示该阶段的全局均排；固定阵容后增加本阵容均排，沿用 DataJ 的数值颜色。
- **装备选择浮层**：检测底部3～5项选择，查询普通成装、神器/奥恩装备和光明装备；显示全局、本阵容均排及最多两位持有英雄，忽略普通散件。光明装备的真实画面验收范围见下文。
- **单条件检索**：使用一个装备、转职、海克斯、英雄或羁绊档位筛选阵容，支持搜索、收藏和排序。
- **固定阵容与攻略**：点击卡片固定阵容，复制主阵容码、查看原站攻略、点击英雄查出装；变体阵容码在原站复制。
- **紧凑悬浮界面**：左上角可展开、收起和拖动，在“识别 / 设置”中调整窗口和字体。

自动模式约每3秒检查海克斯阶段、每2秒探测装备选择区域。手动补查始终保留；识别只在目标游戏前台且助手面板收起时工作。应用不替用户点击或操作游戏。

## 快捷操作

| 操作 | 入口 |
| --- | --- |
| 立即补查海克斯或装备 | 鼠标后退侧键，或 `Ctrl+Alt+F10` |
| 展开 / 收起助手 | 左上角“阵容助手 · 展开”，或 `Ctrl+Alt+F9` |
| 退出助手 | “退出助手”、窗口关闭按钮，或 `Ctrl+Alt+F12` |
| 开始下一局 | 点击“新的一局”，清除上一局的阵容与条件 |

鼠标侧键可在“识别 / 设置”中改为前进侧键或关闭。如果鼠标驱动将侧键设成了键盘宏，可使用键盘快捷键补查。

## 更新与数据位置

退出旧助手，将新版完整解压到新文件夹，再运行新 EXE。当前无自动更新。

便携版的设置、缓存、头像及日志保存在 `%LOCALAPPDATA%\TFT-DataJ`，更新程序时会继续使用。同一电脑从源码版迁移时，原 `work/companion` 下的数据不会自动搬到便携版目录，需要重新确认设置与统计版本。每局开始请点击“新的一局”，当前不会自动识别新对局或游戏补丁。

## 验证范围与已知限制

- **已通过**：59项单元测试、阵容操作流程、9项综合交互，以及实际 ZIP 解压后的 EXE 隔离启动检查。检查覆盖界面资源、OCR模型、内置网页、真实2-1截图识别和“黑暗仪式”筛选回归。
- **跨电脑验证边界**：隔离测试在构建机上运行，使用中文及空格路径，并清理 Python 环境路径；尚未在第二台实体电脑及不同硬件上实测。本版未做代码签名，不提供 Mac、Linux 或 Windows ARM 原生包。
- **识别覆盖**：识别不确定时会拒识或不显示数据。罗马数字等级、不同分辨率与动态画面仍有覆盖限制；装备的成装、神器经过S18录像回放，光明选择及MuMu高清装备正例尚待验收。
- **实战性能**：真实侧键到浮层的总延迟、游戏帧率影响、装备浮层的完整点击穿透仍需实机验证。不能将离线识别耗时作为实战延迟承诺。
- **数据口径**：助手查询使用所选版本；攻略嵌入页的版本由原站控制，需要核对。网络失败、缺少阵容统计或没有足够样本时可能不显示结果。

详细记录：[检索器修复](https://github.com/Robin-hhc/TFT-DataJ/blob/v0.2.1/outputs/检索器最小样本修复-20260928.md)、[装备接入与验证](https://github.com/Robin-hhc/TFT-DataJ/blob/v0.2.1/outputs/装备选择接入与验证-20260928.md)、[构建与便携验证](https://github.com/Robin-hhc/TFT-DataJ/blob/v0.2.1/packaging/README.md)。

## 遇到问题

- **启动失败或闪退**：确认 ZIP 已完整解压且 `_internal` 在 EXE 旁，运行包内“检查运行环境.cmd”；结果位于 `%LOCALAPPDATA%\TFT-DataJ\portable-check.json`，启动日志为同目录的 `run-*.log`。
- **选择界面没有显示数据**：收起助手、让 MuMu 保持前台，按一次鼠标侧键或 `Ctrl+Alt+F10`；检查“识别 / 设置”中的连接状态和统计版本。
- **反馈问题**：到 [GitHub Issues](https://github.com/Robin-hhc/TFT-DataJ/issues/new) 提供助手版本、Windows/MuMu版本、分辨率及缩放、复现步骤。识别问题可附选择画面截图，启动问题可附日志中的错误段落。
