# v0.2.10 · 加快定阵海克斯排名

2026-10-09 · Windows 10/11 x64 便携测试版。

[下载便携包](https://github.com/Robin-hhc/TFT-DataJ/releases/tag/v0.2.10)，先退出旧助手，完整解压后运行 `TFT-DataJ.exe`；保留 `_internal`，无需安装Python或OCR。原有设置与缓存保留。

## 改动

- 定阵时预读海克斯主表；已有排名先显示，缺项补查逐项补上，不等待最后一个慢请求。
- 当前三项独立补查最多三项并行，复用连接与相同在途查询；海克斯使用独立后台队列，缓存不再被慢攻略请求挡住。
- 刷新后过时任务停止继续发送和发布，同组未完成查询不重复排队；已显示的有效排名保留。
- 保留普通请求节流、共享失败冷却、精确版本/阶段/阵容校验及后继画面确认，晚成功不会取消失败冷却。

## 验证

新增20项延迟与并发回归。源码门槛637项、356组冻结数据显示、已核对3-2原图1/1及8项故障注入检查均用于发布验收。

本机同组真实HTTPS空缓存查询7.047→3.266秒；预读主表后三项未缓存补查的一次测量为首项0.203秒、全部0.250秒。探针的身份、阶段、均排及样本一致。数字不含截图、OCR或游戏FPS，不保证其他网络下同样延迟。

[原因、测试与计时范围](../testing/hex-comp-latency-20261009.md)。隐藏Qt截图验证部分排名先显示、其余随后补上。本轮不启动MuMu；实际ZIP离线/联网EXE诊断、CI及ZIP/checksum附件核验通过后才公开发布。
