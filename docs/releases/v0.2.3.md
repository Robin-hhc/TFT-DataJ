# v0.2.3 · 定阵攻略页面修复

Windows 10/11 x64 便携测试版。修复已固定阵容后仍显示“先找到这局的方向”的问题，并明确攻略网页与助手查询所用的统计版本。

## 下载与升级

下载本页附件 `TFT-DataJ-0.2.3-windows-x64.zip`。先退出旧助手，再完整解压到新文件夹并运行 `TFT-DataJ.exe`。无需安装 Python 或 OCR 环境，请保留旁边的 `_internal` 文件夹。

设置与缓存继续使用 `%LOCALAPPDATA%\TFT-DataJ`。新代码需要重新启动助手才会生效；不要同时运行两版。默认鼠标后退侧键补查，`Ctrl+Alt+F10` 同样可用，`Ctrl+Alt+F12` 退出。

## 本版改动

- 已固定阵容与尚未选择阵容使用不同提示，避免定阵成功后再次要求“去选阵容”。
- 统计版本与原站最新版本一致时直接显示攻略；不一致或版本信息尚未确认时，显示固定阵容和“查看原站最新攻略”入口。
- 打开最新攻略后注明网页与助手统计的版本。阵容码、强化和出装查询继续使用所选版本。
- 版本列表晚到时刷新攻略状态，保留当前选中的页面。
- 切换阵容、取消定阵和详情加载失败后重试会清除旧攻略状态与打开最新攻略的选择，避免带入另一套阵容。

## 验证范围

包含真实 Qt 界面的定阵、版本差异、延迟回调、切换与重试回归；沿用四类数据显示回放及数据故障注入。便携包在仓库外中文目录解压并运行实际 EXE，检查定阵页面、OCR、WebEngine、TLS 和源码目录隔离。

已有本机界面验证确认“裁决螳螂”固定后可打开原站攻略并显示英雄头像与过渡信息。便携包验证在构建电脑上执行，其他实体电脑及独立多局游戏性能仍待补充。本版沿用 v0.2.2 的性能改动，未重新宣称新的性能提升。
