# v0.2.11 · 定阵后全量预读海克斯

2026-10-09 · Windows 10/11 x64 便携测试版。

[下载便携包](https://github.com/Robin-hhc/TFT-DataJ/releases/tag/v0.2.11)，退出旧助手，完整解压后运行 `TFT-DataJ.exe`，保留 `_internal` 文件夹。无需安装Python或OCR环境，原有设置和磁盘缓存保留。

固定阵容后立即预读主表及未来海克斯阶段的缺项，不等待攻略详情；当前或下一阶段优先。后台最多一路HTTP，未缓存请求间隔至少一秒，当前选择查询暂停新后台工作，同项已发请求共享结果。

预读的主表、有效排名和成功查询的空结果在本局定阵期间保留，超过十五分钟也可直接读取。换阵容、版本、新一局、取消固定和退出会清除本局缓存并取消旧任务；普通刷新和收起面板保留结果。补查仅留目标阵容与来源记录，减少驻留数据。

全量预读需要时间，未完成的当前选项仍即时补查并逐项显示。来源未提供统计的条目仍显示缺数据，不借其他阶段或全局均排填补。后台预读不新增截图或OCR，选择期间约0.5秒画面检查保持原机制。
