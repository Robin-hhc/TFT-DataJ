# 阵容助手紧凑交互调研

调研时间：2026-10-07（Asia/Shanghai）。范围：窗口收起、阵容固定、搜索入口、列表排序与样本筛选。仅采用产品官方页面、官方使用指南及官方更新记录；本轮没有安装或操作其他助手，也没有验证它们在 MuMu 上的表现。

## 结论

建议把浏览和定阵收敛为同一个工作区：从卡片直接固定阵容，固定后以一行名称和动作栏表示上下文；搜索只保留一个输入框；列表工具栏只保留平均排名、出场率、最小样本。右上角承担收起，真正退出放到原收起位置，并给两个动作清晰的图标和提示。

这是对当前需求的设计建议，不是声称其他产品已经采用完全相同的布局。最有依据可直接借鉴的模式，是 MetaTFT 的“列表卡片固定 → 展开详情”，以及 TFT Academy 的“可辨识入口 → 独立显示与交互 → 收起不牵连其他浮层”。

## 五个可落地的精简模式

以下均是本项目的建议，具体尺寸需以现有小窗的截图和点击验证确定。

1. **标题栏直接放主要窗口动作。** 右上角使用“面板向内收拢”的线条图标，悬停提示“收起助手”；退出仍用 ×，移到用户指定的原收起位置，提示“退出助手”。收起后的入口保留简短可读文字或展开符号和提示，避免仅留下无法判断用途的装饰图标。此处依据用户的明确位置要求；图标辨识借鉴 [TFT Academy 给入口补文字的修订](https://tftacademy.com/overlay/updates)。

2. **单行固定阵容栏。** 未固定时不显示空的“本局阵容”大框；在每个阵容条目提供“定阵”。固定后显示“阵容名 · 复制码 · 攻略 · 换阵”，而非额外叠加一套大导航卡。新的一局保留为紧凑的次要动作，仍可明确清空本局状态。模式参考 [MetaTFT 的卡片固定和展开详情](https://ghost.metatft.com/how-to-use-the-metatft-app/)；不复用收藏图标表示局内固定，避免状态含义不清。

3. **共享搜索框，结果按作用分组。** 输入框提示“搜阵容 / 海克斯 / 装备 / 英雄”；输入文字可以匹配阵容名称，并展开“检索条件”的候选项。用户点击候选后才设置条件；条件显示为可清除标签，阵容文字查询单独可见。回车优先选中明确高亮的候选，没有高亮时执行阵容名称筛选。合并的是输入空间，不改变 [DataJ 条件检索与结果筛选](https://www.dataj.cc/explorer) 的语义。若名字同时属于阵容和资源，应显示类别，不猜用户选哪一种。

4. **一行列表工具栏。** 仅放“平均排名”“出场率”“最小样本”。前两项是互斥排序动作，样本是过滤阈值；显示升降方向，让用户知道均排越小越好、出场率越高越靠前。点击样本只改变阈值，不应默默改排序或清掉条件。卡片本身保留关键英雄头像、阵容名、均排和出场率；更多统计进入详情。依据 [DataJ 阵容页](https://www.dataj.cc/comp) 的统计项目，省略范围来自用户要求。

5. **异常才显示重试，不保留常驻刷新。** 正常时列表自动随版本和条件更新；请求失败时在结果区给出版本/条件范围和“重试”。没有结果要区分“筛选后无匹配”与“请求失败”，清除筛选和重试不能共用一个模糊按钮。这个处理是本项目建议；本轮没有查到足够一手材料证明其他助手使用相同重试策略。

## 推荐信息顺序

```text
标题与版本                                退出 ×  收起图标
搜索阵容 / 海克斯 / 装备 / 英雄…             从游戏取
已选条件（有条件时）                 刚选资源（有记录时）
平均排名 ↓             出场率             最小样本 100
阵容列表 / 固定阵容与攻略
```

固定状态尽量嵌入内容区域顶部，列表和攻略仍保留快速切换。不要把“本局资源”“定阵”“数据加载状态”再次扩展成多层介绍框。搜索建议在需要时展开，空闲状态不占额外纵向空间。

## 改版验收重点

- 右上收起不结束进程，重新展开恢复输入、条件、固定阵容和攻略位置；退出实际结束程序。
- 收起侧栏不隐藏或重置正在展示的海克斯与装备排名，不新增鼠标遮挡区域。
- 只有一个常驻文本输入；阵容名称筛选、点选检索条件和清除条件各自可验证，没有隐式双重过滤。
- 均排、出场率和样本变动后，数据顺序、过滤、条件范围、版本标签一致；沿用真实数据回放验证。
- 未固定、固定中、固定失败、无结果、请求失败、重新开始一局均有紧凑且明确的状态。
- 常用分辨率及 Windows 150% / 200% 缩放下截屏检查标题动作、搜索建议、样本数值、长阵容名和主要按钮，避免布局压缩导致覆盖或截字。
