## 本轮修复的验证问题

- Qt原生 `QLineEdit.setCompleter` 会在点击回调后自动回填候选字符串，造成条件查询后再按“海克斯·名称·品质”筛阵容而得到空列表。改为 `QCompleter.setWidget` 接管弹出候选与明确身份选择，保留原文字；真实点击及键盘回归覆盖该问题。
- 原稳定浮层测试硬套主屏192 DPI，而离桌自有窗口实际属于120 DPI副屏，导致尺寸按1.6倍膨胀。HEAD版生产类对照复现同样5项失败，排除了本次UI回归。测试改为读取自有HWND的实际 `GetDpiForWindow`，保留真实Win32操作、40次重复呈现、无重绘/重复定位及像素不变断言。生产识别和浮层算法未因此修改。
- 最终Spec审查发现历史统计下打开最新攻略时，版本文字虽然更新但被隐藏。已恢复跨版本时的紧凑可见提示，并将原生命周期测试和实际EXE诊断增加可见性断言；同版本时继续精简重复说明。Standards审查未发现需修复问题。

本轮验证界面、数据和本机可执行包，不代表新增真实对局OCR、跨显示器首次移动或游戏FPS验收。
