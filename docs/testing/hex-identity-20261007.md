## 修复约束

- 启动及切换统计版本时，将原有目录请求与全局海克斯预热放到同一工作任务中；没有增加请求数或常态截图频率。
- 完整同名集合的名称、赛季、品质、图标、描述必须非空且严格等价，才可映射到该版本全局统计中唯一存在、至少有一个有效阶段数据的 ID。保留 `catalog_alias_ids` 供追溯，不按均排大小、阵容样本或当前阶段猜身份。
- OCR、手动条件选择和本局已选资源共享同一份目录投影。原始响应不修改；历史版本缺数据、统计失败、两个 ID 都有记录时不合并。旧 adapter 和旧目录 generation 的回调不覆盖当前目录。
- 真正不同品质的同名项仍全部保留。除原有独有英雄名称证据，描述可用两个完整、独有的数值与单位词区分；同两个词须在两次高置信描述读数中出现，任何相反候选词均否决。标题仍需两次精确匹配。
- 数字 `1`、字母 `l`、竖线不替换成 `I`；单靠罗马数字笔画仍仅提出待确认建议。
- 界面按失败边界显示“名称 / 等级 / 品质 / 身份待确认”。未确认身份仍不查询其排名。
