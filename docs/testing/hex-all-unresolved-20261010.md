## 实际修复

采用 [海克斯动画恢复与标题共识规范](../specs/hex-animation-recognition.md)。

动画期间只保留回合、标题与必要说明的区域坐标，清理旧结果，不保存旧身份、旧统计或整张帧作为恢复门控。复用选择期间已有的 **0.5 秒截图**检查小区域；持续不可读的帧不重复 OCR、HTTP 或自动归档。

第一张标题签名可验证的帧立即排队 OCR，解除上一张动画留下的 1.5 秒冷却和 2 秒重复读取门槛。即使此前没有任何已确认结果，也要再由后续独立帧确认，才能发布排名或归档稳定的目录缺名结果。回合暂未读出不会绕过这一门控，回合未确认也不会显示排名。退出选择、进入装备选择、失去前台或上下文失效均清理门控；过期回调不能恢复旧排名。

“秘法帮派 II++”原图的 OCR 输出混入 `ⅡI++`，但二值图与宽图各有一条正确的完整标题。旧实现要求两条正确读数出现在同一重试分组内，错误丢弃跨视图共识。现在允许直接 OCR 视图之间组成共识，仍要求至少两条置信度不低于 0.90 的完整、精确、无冲突标题。只有一条合法标题时，最多增加一次原色紧裁图补读；缺目录或冲突不加读，不删除加号，不改写罗马数字，不降低阈值。

公开回归只包含匿名标题裁图 `outputs/companion/fixtures/hex-arcane-title-20261010.png`，不公开玩家整屏。原图和裁图哈希、裁切范围、来源身份与阶段统计在对应 JSON 中记录。
