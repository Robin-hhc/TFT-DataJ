## 第一版承诺的三个场景

- 海克斯选择时自动识别回合和候选，在卡片附近显示阶段均排；定阵后增加该阵容均排。
- 侧栏提供单条件检索、最近查询和可手动维护的资源标签。
- 用户明确固定阵容，侧栏显示其原站攻略，并提供阵容内强化和英雄装备统计。

DataJ 当前内部入口已定位，四类核心查询已取到结构化结果并完成典型行对照。MuMu 全屏截图、浮层显示、面板收起后焦点恢复已有实测证据。历史/赛季未确认图片的 OCR 布局试验为 4/4 回合、10/12 卡名，不计入 S18 验收；两处 I/1 误识别保留并拒绝强配。接口稳定性、使用条件、窗口场景完整覆盖和实战识别效果仍需验证。

目标为本机 Windows 10 专业版 19045 x64 上的 MuMu 全屏；侧栏采用快捷键展开/收起的浮动面板。MuMu 版本、画布分辨率和发布范围待记录。原窗口模式估算 15–24 人日仅保留为基线，全屏验证后重估。
