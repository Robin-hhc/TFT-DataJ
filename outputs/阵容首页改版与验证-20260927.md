# 阵容首页改版与验证（2026-09-27）

本轮实现已保存至 `E:\tft-helper`。这是本机试用版的一次 UI 改版，不代表全部识别场景验收完成。

## 已实现

- 首页为多套阵容卡片，上方检索器只使用一个装备、转职、海克斯、英雄或羁绊条件；清除后恢复全部阵容。全局与条件内均排分开标注。
- 支持阵容/核心英雄搜索、均排/样本排序、收藏。头像来自 DataJ 图片服务，有本地缓存；头像缺失时显示名称。
- 点击卡片立即固定目标并加载对应攻略；顶部保留复制主阵容码和换阵容入口。详情读取失败清除旧码，可重试。
- 出装页点击本阵容英雄头像即查，支持装备类型和单件/三件套切换。均排颜色与 DataJ 规则一致。
- 支持窗口尺寸预设、大字体、位置保存，小标记可拖动。长英雄名换行显示。
- 修复新局残留旧候选、切回固定卡片未恢复攻略、换阵后旧出装说明残留、头像失败无法重试、异常嵌套响应影响列表等问题。
- 实际 pythonw 启动发现 Qt TLS 探测误载其他软件的 OpenSSL DLL；改为本进程优先使用 Python 配套 DLL 路径，并选择 Windows Schannel。没有修改系统 PATH，也没有关闭证书验证。
