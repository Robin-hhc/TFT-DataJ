# 装备选择接入与验证

2026-09-28。代码已接入 `E:\tft-helper\outputs\companion` 现有助手启动入口。本次完成实现和本地验证，**尚未完成光明选择画面及 MuMu 实机验收**。

## 使用方式

双击 [start-companion.cmd](companion/start-companion.cmd)。需要阵容内数据时，点击一套阵容并收起面板；游戏保持前台，装备选择出现后自动检测。原鼠标后退侧键可随时补查，不必切换识别模式。未定阵只显示全局数据。

- 空闲时每2秒截取游戏下方45%区域，轻量检测重复选项；没有候选区域时不运行装备文字识别。
- 确认选择后按实际3～5项定位，名称严格匹配当前目录。白名单为成型装备、神器装备、光明武器；散件、赐福、混合奖励及未确认项不猜ID。
- 全局和本阵容均排先显示，最多两位持有者异步补齐。持有者至少50局，按均排升序；定阵后严格限制为攻略英雄ID名单，不混入全局数据。
- 显示期间每0.5秒局部检查变化；稳定文字保留结果，不反复请求或隐藏。界面消失、失焦、改阵容、改版本或关闭后清除旧结果，迟到响应不能恢复它们。
- 原海克斯每3秒阶段探测保留，装备与海克斯共用截图、OCR及网络工作队列。

## 验证记录

完整单元测试 **56项通过，无跳过**；下列7个流程脚本全部退出0，未出现未处理异常：

| 验证入口 | 结果及范围 |
| --- | --- |
| `check_item_flow.py` | 真实选择图→装备身份→冻结真实全局/阵容表→持有者测试响应；稳定帧不重查、改变选项立即失效、过期响应丢弃、2秒探测间隔 |
| `check_startup_ocr.py` | 独立新进程、隐藏Qt窗口，连续3次海克斯识别；包含未处理Qt回调异常检测 |
| `check_manual_mode.py` | 原手动查询、空闲不截图、标记尺寸；冻结数据及内存原图下温热流程516ms，不含真实截图/网络 |
| `check_overlay_flicker.py` | 原海克斯截图过程中保持已有浮层 |
| `check_partial_retry.py` | 原海克斯部分识别的有限重试、保留结果及忙碌控制 |
| `check_stage_mode.py` | 3秒阶段检查、目标阶段开启、离开后停止；装备调度单独由装备流程测试覆盖 |
| `integration_check.py` | 原固定阵容、攻略、检索器、英雄出装、新局清理等9项交互 |

识别开发集保持7张原生720P装备正例、33个选项，32项精确确认、1项拒识（薄暮法袍）、无错误ID。散件/赐福/混合奖励及用户现有10张MuMu非装备截图未触发装备结果。样本来自用户认可的 [S18标准模式录像](https://www.bilibili.com/video/BV1wXhD6ZEng/)，画面并未标示具体补丁号；详情见 [初步样本记录](装备选择样本与初步回放-20260928.md)。这些是开发调参样本，不是独立留出准确率。

另取得同一事件第289～293秒的5张原生720P帧，和已有第288、300秒组成连续序列。第288～290秒身份相同，第291～293秒选择消失，第300秒为新选项。来源、哈希、逐格结果在 [连续帧记录](../work/item-choice-samples/stability-sequence.json)。相邻帧不增加独立事件数。

本轮修正两项实际发现的问题：

1. 对象地址可能在版本切换后被Python复用，内存缓存现改为明确的赛季/版本/范围键，增加切换及切回回归。
2. 真实连续帧存在少量压缩亮点，原海克斯文字阈值用于装备时会误判刷新。装备改为逐文字区、1像素邻域及最多5个孤立像素容差；稳定帧仍与原始确认签名比较，避免逐帧漂移。真实刷新及只替换一项名称均能失效。

独立代码和需求审查已完成；缓存修复已定向复查。

## 延迟和仍待验证的部分

仅本地原图测量：960×720成装四选图，20次轻量定位中位5.04ms、P95 5.29ms；引擎预热后10次完整装备识别中位226.76ms、最大234.78ms。[原始计时](../work/item-choice-samples/item-local-timing.json)。这不包含真实截图、排队、网络及Qt绘制，不能当作侧键延迟或游戏帧率结论。自动模式还存在0～2秒探测等待。

未完成项明确保留：

- 光明装备已接入目录分类和统计查询，并有光明统计缺项补查测试，但仍无本赛季真实选择正例，不能宣称识别已验收。
- 原始录播是960×720、带摄像头及黑带的4:3画布，尚缺MuMu 16:9高清装备正例和独立对局留出集。
- 本轮枚举未找到MuMu游戏窗口；未开启匹配、未验证真实侧键到浮层延迟、装备点击穿透、前后台完整链路和开启助手前后的FPS/帧时间。不能据回放声称不影响游玩。
- DataJ非稳定公开API，部分响应不回显请求版本；实现按所选版本传参并隔离缓存，但不代替来源端版本正确性保证。
