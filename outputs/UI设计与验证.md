# 桌面 UI 改版

2026-09-26。工作目录 `E:\tft-helper`。

## 视觉依据

实际查看了 [DataJ 强化符文统计](https://www.dataj.cc/hex) 的页面：深色背景、金色当前导航与强调、分层表面、紧凑表格、分色的均排数值。结合既定方案中“局内浮层与查询面板分开、全局与阵容统计分别标注、一键启动”的要求进行桌面适配。没有复制网站 Logo、英雄背景或网站代码；使用本地绘制的几何标记与 Qt 样式。

## 已实现

- 左侧固定导航：局内辅助、条件选阵、阵容攻略、英雄出装；四页共享本局阵容信息。
- 首页主按钮保持“开始辅助”；三张结果卡分别显示候选名称、全局均排、样本数与阵容内均排。未知值显示横线及原因，不生成示例统计。
- 条件选阵采用左侧搜索/最近条件、右侧阵容列表。普通条目隐藏内部 ID；同名同品质冲突项保留来源编号供区分，手动纠错仍可查看 ID。
- 攻略未打开时提供说明和选阵入口；嵌入页面保持 DataJ 自己的样式与权限隔离。
- 输入框、表格、按钮、滚动条、空状态和游戏浮层统一深色/金色风格。均排分色只辅助阅读，样本数始终保留，不表示因果收益。
- 高级设置默认折叠。小窗口与展开高级设置使用页面滚动，不挤出窗口或遮挡底部状态。

## 验证范围

8 种页面/状态渲染通过，所列预览检查无横向溢出；小尺寸覆盖首页，攻略覆盖空状态。验证重复点击导航保持高亮、同名查询项可区分、结果卡与冻结查询响应连接、候选失效后清空数值及未识别时不显示数值。已有 20 项单元测试、9 项简化流程、9 项冻结界面与 6 项异步回归通过。
