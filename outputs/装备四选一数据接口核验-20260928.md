# DataJ 装备四选一数据核验（2026-09-28）

仅做研究；未改生产代码、未操作 Git。以下数值是本次来源快照，不是推荐结论。

## 直接接口：全部实测

共同前缀 `https://www.dataj.cc/api/web`；GET 参数 `setId=18&gameVersion=18.2a`。

| 用途 | 路径 | 响应 data 结构 / 关键字段 |
|---|---|---|
| 全局全部单装备统计 | `/stats/equip` | list；equipId,name,picture,sampleCount,avgPlacement,playRate,top4Rate,topRate,recommendedHeroes |
| 指定阵容单装备统计 | `/comp/112/equips` | compId,equips[]；每行 equipId,type,sampleCount,avgPlacement 等 |
| 全局单装备持有者 | `/stats/equip/2004/heroes` | list；heroId,name,picture,price,sampleCount,avgPlacement,tier,placementDelta 等 |
| 阵容单装备持有者 | `/comp/112/equip-heroes?equipId=2004` | compId,equipId,heroes[]；heroId,heroName,price,sampleCount,avgPlacement,tier,placementDelta 等 |

四条均返回 HTTP 200、success true、code 200。全局 /stats/equip 本次一次返回138条，可按装备ID一次缓存整表；阵容表本次68条。原始快照 `work/item-choice-probe/{global,comp,holders,comp-holders}.json`，每个文件第2行记录完整请求URL，第3行起payload。

- 朔极之矛 2004：全局均排4.22、sampleCount147622；地狱火95（112）内均排3.56、sampleCount31188。
- 大亨之铠 6052：全局4.51、5623；该阵容3.61、546。
- 光明版无尽之刃2059：全局4.13、1637；**该阵容 /equips 返回68行且无任何光明武器，不能把缺行理解为无对局。**
- 额外实测 `/stats/equip/6052/heroes`、`/stats/equip/2059/heroes`、`/comp/112/equip-heroes?equipId=2059` 均成功；最后一条希维尔137样本、均排3.55，表明阵容光明持有者数据实际存在。
- 持有者行不带 starCount；不可写成特定星级结果。不同heroId可能同名（如拉克丝、克格莫），必须按ID保留身份。
- 全局表 recommendedHeroes 只有英雄身份和sampleCount，没有均排；不可把该字段直接称为“均排最优英雄”。需要独立 /heroes 数据排序。
- 阵容 equip-heroes 可能含不在攻略默认九人名单内的英雄（变阵/临时持有者）；默认推荐可优先与已固定阵容英雄ID相交，详细页注明其它观察到的持有者。

## 版本核验

相同 /stats/equip、setId18，gameVersion18.1 与18.2a：2004分别为4.36/69615与4.22/147622，证明这两次版本参数查询返回不同统计。快照 `global-18.1.json`。响应数据不回显gameVersion，客户端只能保留请求版本标签；对照只证明上述两次返回不同，不能因此声称服务端所有路径严格隔离或所有历史版本完整可用。

## 设计限制与建议（非已实现）

- 全局/阵容均排是观察数据，不等于拿装备可改善多少名次；高费英雄低均排有幸存者偏差。推荐标题“持有者参考”，带样本，优先已定阵英雄；样本阈值至少50，低样本不排序为强推。
- 同屏4项先展示均排，英雄数据异步补齐；不要等待8个持有者请求后才渲染均排。
- 原始3个补充GET本次耗时约0.12/0.03/1.55秒，**仅一次网络请求计时，不是端到端性能证明**。已有适配器网络请求串行最小1秒，冷场景8个请求不能承诺1秒内完成；需要预热/缓存和渐进展示。
- 尚未验证装备四选一真实UI识别、各种光明/神器图标区分、全品类覆盖、接口稳定性/官方授权；此次只验证数据可访问和具体字段。
