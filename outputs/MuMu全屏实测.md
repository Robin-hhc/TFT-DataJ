# MuMu 全屏 P0 实测

实测跨 2026-09-25 / 2026-09-26，Asia/Shanghai。本轮从文档推进到可运行的验证工具；没有接入正式 OCR 或自动均排浮层。

后续更新：测试程序已正常退出，日志无未处理错误。之后按用户建议改用网上图片推进离线 OCR，见 [公开截图 OCR 验证](公开截图OCR验证.md)；无需为当前开发专门开局。本报告保留第一轮全屏测试范围。

## 已取得的结果

| 项目 | 本次证据 | 结论边界 |
|---|---|---|
| 目标窗口 | MuMuNxDevice.exe；实际前台窗口“MuMu安卓设备”，客户区和显示器均 `(0,0,3840,2160)` | 已定位全屏游戏窗口；并未判定独占/无边框具体实现 |
| DPI | GetDpiForWindow=192，200% 缩放 | 坐标必须区分逻辑尺寸与屏幕物理像素 |
| 全屏截图 | mss 取得 3840×2160 的模式选择页及大厅，人工查看图像可读、未黑屏 | 证明本机当前配置能截图；非所有场景兼容结论 |
| 浮层显示 | 截图可见左上角“MuMu 浮层测试” | 已能覆盖当前 MuMu 全屏 |
| 不抢焦点与点位命中 | 浮层显示后前台 HWND 仍为 MuMu；浮层内取点 WindowFromPoint 的根窗口为 MuMu | 支持不截获点位的判断，实际点击仍需要用户体验确认 |
| 面板/焦点 | 00:03:22 收到 F9 组合键并打开面板；00:03:29 收起后观测前台为原 MuMu HWND | 一次实际打开/收起和焦点恢复闭环通过 |
| 截图后恢复 | 用户从面板请求截图，保存成功；随后 overlay_visible，点位仍落到 MuMu | 已验证截图隐藏回退及恢复路径 |
| 失焦隐藏 | 00:03:36 切到其他窗口，状态变为 not_foreground 并隐藏 | 已观测一次失焦路径；仍需补全屏退出/恢复、多屏/DPI切换 |
| Qt 截图排除 | 首轮 Set/GetWindowDisplayAffinity 组合结果为 false；普通截图含测试浮层 | 不能依赖此能力；先隐藏再截图的回退已实测，无需绕过系统设置 |

前三次截图调用分别约 **181.90、157.51、106.36 ms**。包含 mss 创建/抓图，不含 OCR、DataJ 查询和 PNG 保存；样本仅 3 次，不报告 p95 或帧率影响。第三张是工具面板触发的隐藏浮层截图，人工查看未见测试标签。MuMu 自己的键位提示仍存在，后续 OCR 样本必须包含这类遮挡。

## 本轮交付

[MuMu 验证工具说明](mumu-p0-probe/README.md) 与 [启动入口](mumu-p0-probe/start-probe.cmd)。程序运行在工作区独立环境，不改动系统 Python 或 MuMu 设置。支持显式单帧截图、绑定窗口、快捷键面板、失焦隐藏及 5 分钟自动退出，不联网、不操作游戏。

已使用的依赖：Python 3.12.14 x64、PySide6-Essentials 6.8.3、shiboken6 6.8.3、mss 10.2.0、Pillow 11.3.0。Qt 组件下载曾停滞，改为下载 PyPI 的同一官方 wheel，核对 PyPI SHA-256 后本地安装；不是换用其他来源。Qt WebEngine 和 OCR 引擎尚未安装或验证。

## 验证与审查

- 4 个窗口/截图条件测试通过：前台限定、句柄复用时 PID 改变、最小化拒绝、负坐标显示器全屏几何。
- 窗口构造及 Qt 输入透明/不接收焦点属性检查通过，依赖完整性检查通过。
- 按标准与规格两个独立方向审查，均发现同一处截图回退后浮层不恢复的问题；已通过使显示状态失效并重新检查前台修复。后续真实面板截图证明该回退路径恢复。
- 快捷键记录移至执行退出动作之前，避免退出清理后再写日志。全部作用域仅为本次 P0 工具。

这是 projectless 工作目录，没有伪造 Git 历史、创建远端仓库或发布安装包。源码和工作区依赖可供下一轮复现；不将试验程序直接当成产品架构。

## 仍未通过的验收项

1. 用户实际点击体验的最终反馈，以及进入/退出全屏、最小化恢复、多屏/DPI切换组合。
2. 本机 MuMu 具体版本、内部游戏渲染分辨率与渲染模式；本轮已确认的 3840×2160 是桌面客户区尺寸。
3. 真实海克斯选择画面、回合与三名称 OCR；未采集到这类图像，不能用大厅文字代替识别验收。
4. 选择刷新、短动画、错名拒识、数据迟到失效的完整闭环。
5. DataJ 更多边界查询、目录版本差异、使用条件与 Qt WebEngine 页面兼容。

因此，**T03 已有本机全屏运行证据，但尚未全部通过；T04/T08 尚未开始真实识别评估**。下一步应在用户正常对局遇到强化选择时保存少量样本，先确定回合和名称区域，再建立按对局分离的标注集。
