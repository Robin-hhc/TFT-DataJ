# 紧凑界面与版本筛选

- 移除系统标题栏，保留应用内退出、收起、标题拖动和右下角调整大小。
- 顶部移除说明副标题与重复快捷键行，缩短间距和目标阵容栏。
- 左下角改为统计版本下拉框，读取 DataJ 阵容页提供的版本列表。当前验证到 18.2a、18.2、18.1.c、18.1b、18.1。
- 选择版本立即更换查询适配器，清空旧阵容、排名和装备结果，阻止旧请求覆盖新版本。GET 统计使用 gameVersion，检索器 POST 使用 version；缓存按版本隔离。
- 阵容卡显示完整英雄名单、主 C 标记、评级、羁绊、均排、前四率、登顶率和样本数。英雄保持费用颜色和名称，超过十个自动换行。

验证：44 项单元测试通过，阵容浏览、单条件检索、定阵、复制、旧请求隔离、关闭和冷启动识别检查通过。真实数据对照：18.2a 阵容列表为 35 套、地狱火95 均排 3.73；18.2 为 36 套、对应均排 3.57。数值为当时接口返回，后续可能变化。

限制：来源攻略网页不响应已尝试的 gameVersion/version URL 参数，初始内容仍为最新版本。为了避免混显，选择历史版本时不嵌入最新攻略页；助手提供的阵容码、强化及出装查询仍按所选版本执行。18.2a 当前最新版本的内嵌攻略照常可用。此处没有宣称完成历史攻略适配。

来源：[DataJ 阵容排行](https://www.dataj.cc/comp)。预览保存在 work/companion/compact-ui-preview.png，使用实际数据和头像渲染；不包含系统标题栏。
